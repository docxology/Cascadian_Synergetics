# Cascadian Synergetics documentation

The [repository README](../README.md) introduces the two patrols, controls,
and released editions. Use these guides to work on the sources:

- [Develop and verify](development.md) explains the page build, local
  commit checks, vendor verification, and screenshot workflows.
- [Build the paper](manuscript-build.md) registers the project with the
  pinned Template renderer and verifies its PDF.
- [Manuscript source](manuscript/README.md) records the authored sections,
  configuration, bibliography, and figure inputs.
- [Game design](design.md) describes the patrols and visual rules.
- [Synergetic geometry](synergetics.md) explains the measurements.
- [Imports](imports.md) records the upstream pins and coordinate conventions.
- [Cascadia](cascadia.md) gives the setting’s geographic and historical sources.

The [released PDF](../output/pdf/Cascadian_Synergetics_combined.pdf) and its
[source binding](../output/pdf/Cascadian_Synergetics_combined.json) are
publication artifacts. Use a disposable checkout to verify a fresh render.
